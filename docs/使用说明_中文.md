# 离体牙 micro-CT 牙体组织分割模型使用说明

本模型基于 nnU-Net v2 的 `3d_fullres` 配置，自动分割离体牙 micro-CT 影像中的**牙釉质、牙本质和牙髓腔**，输出多类别NIfTI分割标签。

## 模型基本信息

- 数据集：`Dataset413_microctbycsm`（ID 413）
- 训练器：`nnUNetTrainer`
- 权重：`fold_0/checkpoint_final.pth`
- 输入：单通道 micro-CT NIfTI（`.nii.gz`）
- 数据集元数据记录：100例；Fold 0内部验证记录：20例
- 预处理目标体素间距：约0.0418 mm（根据模型规划文件）

## 标签定义

| ID | 类别 | 原始标签名 |
|---:|---|---|
| 0 | 背景 | `background` |
| 1 | 牙髓腔 | `pulp_cavity` |
| 2 | 牙釉质 | `enamel` |
| 3 | 牙本质 | `dentin` |


macOS/Linux环境示例：

```bash
export nnUNet_results="$HOME/nnUNet_results"
mkdir -p "$nnUNet_results"
nnUNetv2_install_pretrained_model_from_zip /path/to/Dataset413_model.zip
```

## 分割预测

准备输入文件：

```text
imagesTs/
├── tooth001_0000.nii.gz
└── tooth002_0000.nii.gz
```

执行：

```bash
nnUNetv2_predict \
  -i ./imagesTs \
  -o ./predictions \
  -d Dataset413_microctbycsm \
  -c 3d_fullres \
  -f 0 \
  -tr nnUNetTrainer
```

输出 `predictions/tooth001.nii.gz` 等分割结果。它们是按0–3编码的多类别标签，不是单独的三个二值文件。

## 模型验证

模型的Fold 0内部验证记录包含20例，三个类别的Dice分别为：牙髓腔 **0.9528**、牙釉质 **0.9693**、牙本质 **0.9827**；前景类别平均Dice为 **0.9683**。详细数值见 `docs/VALIDATION.md`。
